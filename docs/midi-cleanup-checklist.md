# MIDI transcription cleanup checklist

Automatic audio-to-MIDI output is a draft. Review it in this order so later edits do not conceal earlier transcription problems.

## 1. Pitch

- Remove notes that are unrelated to the audible part.
- Correct octave errors before editing timing.
- Compare repeated phrases for inconsistent pitch choices.

## 2. Onsets

- Align notes that begin clearly early or late.
- Use light quantization only when the performance is intended to follow a grid.
- Listen before and after quantization; do not assume a smaller visual offset sounds better.

## 3. Durations

- Shorten overlaps that should not be legato.
- Extend notes that were cut off.
- Check sustain-pedal passages separately from note lengths.

## 4. Velocity

- Remove accidental spikes after the correct notes and timings are in place.
- Preserve intended accents and phrase shape.

## 5. Final checks

- Solo the MIDI against the source recording.
- Inspect the beginning and end for tiny stray notes.
- Save the untouched transcription beside the cleaned version.
- Record every manual change if the result will be used as benchmark data.
